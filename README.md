### 🚀 Featured Projects

#### 📄 [AI-Powered Resume Builder Platform](https://github.com/Arvindkumar-star/AI-POWERED-RESUME-BUILDER-PLATFORM)
A multi-agent AI system where four specialized agents collaborate to write, optimize, and score resumes in real time — including a 10-metric ATS analysis engine.
**Stack:** React, Vite, Node.js, Express, MongoDB, Gemini AI
**Live:** [ai-powered-resume-builder-platform-z2ie.onrender.com](https://ai-powered-resume-builder-platform-z2ie.onrender.com)

#### ❓ [AI Doubt Solver](https://github.com/Arvindkumar-star/AI_DOUBT_SOLVER)
A real-time Q&A assistant powered by a RAG pipeline — retrieves relevant context via MongoDB Atlas Vector Search before generating grounded answers with Gemini.
**Stack:** React, Node.js, Express, MongoDB, Gemini AI, RAG

#### 📝 [AI-Powered Form Generator](https://github.com/Arvindkumar-star/AI_POWERED_FORM_GENERATOR)
Generates fully functional, logic-aware forms from natural language — supports conditional field logic and a full response analytics dashboard.
**Stack:** React, Vite, Node.js, Express, MongoDB, Groq (Llama)
**Live:** [ai-powered-form-generator-1.onrender.com](https://ai-powered-form-generator-1.onrender.com)

#### 🎤 [AI Mock Interview Platform](https://github.com/Arvindkumar-star/AI_MOCK_INTERVIEW_PLATFORM)
Simulates real interviews and gives structured performance feedback to help candidates improve before the real thing.

#### 🎓 [AI Personalized Academic Optimizer](https://github.com/Arvindkumar-star/AI_PERSONALIZED_ACADEMIC_OPTIMIZER)
An AI-assisted academic decision support system — computes objective metrics from structured student data and layers LLM reasoning on top, rather than acting as a plain chatbot.

#### 🖼️ [AI-Powered Thumbnail Generator](https://github.com/Arvindkumar-star/AI_POWERED_THUMBNAIL_GENERATOR)
Creates polished thumbnails in under a minute using AI.
